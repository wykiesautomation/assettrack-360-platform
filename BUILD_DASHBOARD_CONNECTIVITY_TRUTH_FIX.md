# AssetTrack 360 Dashboard Connectivity Truth Fix

- ONLINE requires real device contact within 90 seconds.
- DELAYED applies from 91 seconds through 5 minutes.
- OFFLINE applies after 5 minutes.
- NEVER SEEN applies when no device contact exists.
- HEALTHY is no longer used as a device-connectivity label.
- Historical simulation is retained as evidence but labelled LAST SIMULATED TEST.
- Old physical data is labelled LAST REPORTED VALUE and WAITING FOR BOARD TELEMETRY.
- The page-live badge now reports device connectivity, not merely browser refresh time.
- No readings, customer data, assignments or history are deleted.
