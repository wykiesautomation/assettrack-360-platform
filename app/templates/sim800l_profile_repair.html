SIM800L Profile Repair

Use only after physically verifying the T-Call SIM800L board. No automatic repair. Device UID, token, asset and history remain unchanged.

1. Existing registered device

In Board Builder click READ BOARD & OPEN PROFILE REPAIR. Hardware UID and firmware are filled automatically. If blank, return to Board Builder; do not type identities.

2. Unused claim-code correction (unregistered boards only)

Expired codes cannot be repaired. Generate a new code using the SIM800L card instead. Do not re-claim an existing registered board.
